# Alibaba Product Draft Skill

## Requirements

- Codex with local skills enabled
- Node.js 18+
- `sharp` for AVIF/WebP conversion

## Install

### Option A — from a GitHub repo (recommended)

If the skill lives in a repo such as `https://github.com/<owner>/<repo>/skills/alibaba-product-draft`, tell Codex:

```text
install the skill at https://github.com/<owner>/<repo>/tree/main/skills/alibaba-product-draft
```

Codex's built-in `skill-installer` downloads it into `~/.codex/skills/alibaba-product-draft` automatically.

### Option B — from this archive

1. Extract this archive.
2. Copy the `alibaba-product-draft` folder into your Codex skills directory:
   - Windows: `%USERPROFILE%\.codex\skills\`
   - macOS/Linux: `~/.codex/skills/`
3. Confirm this file exists:

   ```text
   .../skills/alibaba-product-draft/SKILL.md
   ```

4. Start a new Codex session. Skills are discovered at session start.

If `CODEX_HOME` is set, use `$CODEX_HOME/skills` instead of the default path.

## Project setup

From the product project root:

```powershell
npm install sharp
```

Create the input/output layout:

```text
产品/          product images
images/        generated by prepare-images.js
output/        generated draft files
```

If the images are not in `产品/`, pass `--input <directory>` to `prepare-images.js`.

## Run

```powershell
$skill = Join-Path $env:USERPROFILE '.codex\skills\alibaba-product-draft'
node "$skill\scripts\prepare-images.js" --root .
node "$skill\scripts\build-draft.js" --root .
node "$skill\scripts\validate-draft.js" --root .
```

The skill workflow expects the agent to inspect at most three images and write:

- `output/vision.json`
- `output/listing.json`

Then run the build and validate commands.

## Notes

- This skill does not fill the Alibaba page, upload images, save, or publish.
- Company values stay as `{{company.*}}` placeholders and are resolved by the Edge panel.
- Unknown or business-sensitive values go into `missing`.
